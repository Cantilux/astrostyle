Navigation

Ways to move around a site. The breadcrumb is plain HTML and CSS; pagination and tabs get their behavior from small JavaScript modules, wired here by autoInit().

The last item carries aria-current="page". Separators are generated content that screen readers skip; change them with --ap-breadcrumb-separator (a CSS string). Long paths wrap.

Pagination 02

Buttons: pick a page, ap:page reports it here.

Links (data-ap-href): they navigate like any link; at either end the step is disabled.

<!-- links: the server renders each page -->
<nav data-ap-pagination data-ap-page="2" data-ap-count="12" data-ap-href="?page={page}" aria-label="Log pages"></nav>

<script type="module">
  import { autoInit, createPagination } from 'astrostyle/js'
  autoInit(document)

  // buttons: load the page yourself
  const pages = createPagination(nav, { page: 1, count: 12 })
  nav.addEventListener('ap:page', (event) => loadPage(event.detail.page))
</script>

The window keeps the same number of items while you page, so the control never jumps. Options: siblings, boundaries, labels. Cancel ap:page on links to route on the client.
