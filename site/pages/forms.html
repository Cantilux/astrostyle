Forms

Native form controls with a class each: keyboard, validation and screen readers work as the browser intends. Wrap a control in ap-c-field for its label, hint and error.

Field and input 01

Sector or coordinates.

Five letters, no digits.

Read-only.

<div class="ap-c-field">
  <label class="ap-c-field__label" for="course">Course</label>
  <input class="ap-c-input" id="course" aria-describedby="course-hint">
  <p class="ap-c-field__hint" id="course-hint">Sector or coordinates.</p>
</div>

Errors: set aria-invalid="true" on the control and point aria-describedby at the ap-c-field__error text.

Select and combobox 02

Start from a native <select>: it works without JavaScript and keeps posting its value with the form. Add data-ap-combobox and call autoInit() (or createCombobox()) to turn it into a searchable combobox; data-ap-creatable also accepts free text.

Type to filter, arrows to move, Enter to pick.

<select class="ap-c-input ap-c-select" id="ship" name="ship" data-ap-combobox>
  <option value="">Search the registry</option>
  <option value="heron">Night Heron</option>
</select>

<script type="module">
  import { autoInit } from 'astrostyle/js'
  autoInit(document)
</script>

Keyboard: type to filter, ↓/↑ to move (skipping disabled options), Enter to choose, Esc to close and restore, Alt+↓ to open. Events on the select: change, ap:change (detail: { value, label, created }), ap:open, ap:close.
