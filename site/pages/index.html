Style guide 00 / CSS framework

astrostyle

Buttons, inputs, pagination, panels and all the other bits a website needs, dressed in the colors and attitude of the ASTROPRISMA tabletop RPG. SCSS core, plain CSS build, a pinch of vanilla JavaScript, no framework required.

These pages are built with astrostyle itself. Components arrive over the next releases; today you can see the foundations, the element defaults, the layout objects and the utilities.

Install 01

npm install astrostyle
@use 'pkg:astrostyle' as ap;

@include ap.emit;

No Sass? Link node_modules/astrostyle/dist/astrostyle.css and pick a theme with data-ap-theme="light" or "dark".
