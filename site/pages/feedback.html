Toast 06

import { createToaster } from 'astrostyle/js/toast'

const toaster = createToaster()
toaster.show({ title: 'Docked', message: 'All systems are back online.', tone: 'success' })
toaster.show({ message: 'Cargo sold.', action: { label: 'Undo', onClick: undoSale } })
toaster.show({ title: 'Hull breach', message: 'Seal deck 3.', tone: 'danger', urgent: true, duration: 0 })

Toasts close after five seconds; hovering or focusing one stops the clock. Up to three are shown at once, the rest wait. urgent toasts use role="alert"; the others are read politely. Never put the only way to do something in a toast.
